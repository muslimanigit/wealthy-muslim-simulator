# The Wealthy Muslim — Impact Simulator

A static, browser-based simulator for exploring hypothetical charitable giving across Dawah, education, humanitarian, and community-impact initiatives.

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish to GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. Visit `https://<username>.github.io/<repository>/`.

No build step is required.
